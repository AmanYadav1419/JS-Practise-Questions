# 🧠 DSA & LeetCode Questions

Welcome to the **Data Structures and Algorithms** section!

If you are preparing for coding interviews, these are classic foundational algorithmic problems taken from LeetCode and efficiently solved using JavaScript paradigms.

## 📝 What's Inside?

This folder contains a curated selection of coding scenarios ranging from easy arrays strings, sliding scale algorithms, and pointers:

- **`two-sum.js`, `3sum.js`, `3sum-closest.js`**: Classical array and dynamic pointer evaluations.
- **`bestTimetoBuy&Sellstocks.js` & `container-with-most-water.js`**: Maximum profit and area paradigms.
- **`longest-palindromic-substring.js` & `longest-substring-without-repeating-characters.js`**: Complex string evaluations.
- **`median-of-two-sorted-arrays.js`**: Difficult binary search solutions natively built for arrays.
- **`string-to-integer-atoi.js` & `zigzag-conversion.js`**: Structural algorithms.

## 🚀 How to Practice

Try solving these questions analytically in a notebook before evaluating the core algorithm logic here!
You can run each algorithm inside your terminal:

```bash
node 3sum.js
```
