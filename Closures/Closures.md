# 💡 Closures in JavaScript

Welcome to the **Closures** section!

This folder contains everything you need to understand one of JavaScript's most powerful, fundamental, and frequently asked interview concepts: **Closures**.

## 📝 What's Inside?

We cover various theoretical scenarios and practical application examples of closures:

- **`BlockScopeClosure.js` & `closureScopeChain.js`**: Understanding Scope Types and memory referencing.
- **`ModulePattern.js` & `PrivateCounterUsingClosure.js`**: How to keep variables private and create encapsulated modules.
- **`MakeThisRunsOnlyOnce.js` & `OncePolyfill.js`**: Implementing robust polyfills directly utilizing closures.
- **`closures-VS-Scope-Differnce.js`**: The classic interview discussion addressing confusion between Scope and Closure.
- **`memoizePolyfill.js` & `TimeOptimizationQuestionByClosure.js`**: Advancing with application optimization using memoization closures.

## 🚀 How to Practice

Run any of the files locally using Node JS:

```bash
node closureExample.js
```

Or simply open the `index.html` file in a browser to see how they execute inside the browser's console.
