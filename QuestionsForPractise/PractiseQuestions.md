# 🏋️ Questions For Practice

Welcome to the **Questions For Practice** section!

This directory operates as a massive knowledge bank consisting of simple to intermediate DOM logic questions and core loop scenarios.

## 📂 Sub-Directories

- **`BeginnerQuestions/`**: Contains around 20 core structural scripts (`01.js` formats) alongside HTML files for testing DOM renders. They're perfect if you're newly interacting with math iterations, arrays, and standard output generations.
- **`IntermediateQuestions/`**: Contains sequentially numbered components (`20.js` through `34.html` and beyond). Focuses on manipulating arrays of items and parsing deeper application state configurations.

## 🚀 How to Practice

Dive into the respective folders and tackle one numbered logic script per day. Using the included `index.html` testers will allow you to quickly verify graphical results!
