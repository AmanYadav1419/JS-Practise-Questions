# 🚀 JavaScript Practice Questions

Welcome to the **JavaScript Practice Questions** repository! 🌟

This project is a comprehensive collection of JavaScript problems, algorithms, and core concepts. It is created to serve as a **learning hub, teaching tool, and open-source contribution repository**. Whether you are a beginner taking your first steps in JavaScript, an intermediate developer discovering advanced features, or someone preparing for coding interviews, this repository provides hands-on practical questions that will help you level up your skills.

## 📂 Folder Structure

The repository is neatly organized by topics and concepts, so you can easily navigate, find what you need, and test the codes instantly.

```text
JS-Practise-Questions/
├── Closures/
│   ├── ... (Closure concepts, Scope chains & examples)
├── Currying/
│   ├── ... (Currying implementations & polyfills)
├── DSA-LeetcodeQuestions/

│   ├── BeginnerQuestions/
│   └── IntermediateQuestions/

    ├── Files for 20 logic-building problem sets
    └── Questions.md
```

## 👨‍💻 How to Use This Repository

1. **Clone it locally:**
   ```bash
   git clone https://github.com/AmanYadav1419/JS-Practise-Questions.git
   ```
2. **Navigate** through the folders based on the topic you want to master.
3. **Read the code files** to understand the problem statements and solutions.
4. **Experiment!** Run the code using Node.js:
   ```bash
   node <filename>.js
   ```
