# ⚙️ Functions in JavaScript

Welcome to the **Functions** section!

Functions are the core building blocks of JavaScript. Understanding the subtle differences in function execution types, scoping, memory contexts, and output-based anomalies is critical to mastering the language.

## 📝 What's Inside?

We target many output-based questions directly from prominent tech interviews:

- **`ArrowFunctions.js`**: Syntactic sugar breakdowns and understanding the lexical `this`.
- **`CallbackFunctions.js` & `FirstClassFunction.js`**: Assigning functionalities to variadic variables.
- **`WhatisIIFE.js`**: Breakdown of Immediately Invoked Function Expressions limits and states.
- **`FunctionHoisting.js` & `FunctionScope.js`**: Exploring `undefined` outputs vs Reference Errors. Includes associated `*OPBasedQuestion.js` challenges to test your theory!
- **`sArguments.js` & `sArgumentsOPBasedQuestion.js`**: Dealing with the hidden `arguments` instance anomalies.

## 🚀 How to Practice

Each file demonstrates specific console interactions. Play around and check the Node execution context!

```bash
node ArrowFunctions.js
```
