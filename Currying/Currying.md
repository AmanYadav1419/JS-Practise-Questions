# 🍛 Currying in JavaScript

Welcome to the **Currying** section!

## 📝 What's Inside?

Currying is a functional programming technique sequence evaluating functions with multiple arguments into a sequence of unary (single-argument) functions.

In this folder, you will master currying step-by-step:

- **`currying.js` & `whyWeUseCurrying.js`**: Basic setups and explanations of the advantages of currying.
- **`Question1Implementation.js` down to `Question6Implementation.js`**: A methodical progression of implementation for various currying questions and practical use cases showing how to dynamically handle unlimited variables and edge cases.

## 🚀 How to Practice

To test the functions, execute them in standard node environment:

```bash
node currying.js
```
